# Imagens da landing page

Coloque os arquivos abaixo nesta pasta, com **exatamente estes nomes**. A página
já aponta para eles; enquanto um arquivo não existir, aparece um placeholder
discreto no lugar — nada quebra.

| Arquivo | Onde aparece | Formato sugerido |
| --- | --- | --- |
| `cassio-canali.jpg` | Seção "Quem é Cássio Canali" | retrato vertical 4:5, ~1200×1500, foco no rosto |
| `depoimento-1.png` | Grade de prints de depoimentos | print de conversa 4:5, ~800×1000 |
| `depoimento-2.png` | Grade de prints de depoimentos | idem |
| `depoimento-3.png` | Grade de prints de depoimentos | idem |
| `aluno-1.jpg` … `aluno-4.jpg` | Avatares no carrossel de depoimentos | quadrado, ~200×200 |
| `og-canali.jpg` | Prévia ao compartilhar o link | 1200×630 |

Dicas:

- Comprima antes de subir (TinyPNG, Squoosh). Cada imagem acima deve ficar
  abaixo de ~200 KB; a página inteira carrega mais rápido que qualquer ganho de
  qualidade que você teria com arquivos maiores.
- Os prints de depoimento entram como imagem, então **apague ou borre telefone,
  sobrenome e qualquer dado pessoal** antes de publicar.
- Trocar um nome de arquivo exige editar o `src` correspondente em
  `../index.html`.

## Textos provisórios

Os quatro depoimentos do carrossel em `../index.html` são **exemplos de
estrutura**, não depoimentos reais. Substitua o texto, o nome e a legenda de
cada card pelos depoimentos verdadeiros antes de publicar a página — os blocos
estão marcados com um comentário `⚠️ CONTEÚDO PROVISÓRIO`.
